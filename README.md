# 1. Tracking mangrove loss of Sundarbans using landsat data.

### Data link: 
https://figshare.com/articles/dataset/Annual_mangrove_maps_from_1988_to_2022_in_the_Sundarbans/21779636

### Description: 
The following dataset contains 1 dimensional TIFF images of Sundarban satellite images from 1988 to 2022.

### Aim: 
Using Geopandas and Rasterio to understand how land coverage of the Sundarbans has changed between 1988 and 2022. In the project I have explored cumulative loss and net loss.
